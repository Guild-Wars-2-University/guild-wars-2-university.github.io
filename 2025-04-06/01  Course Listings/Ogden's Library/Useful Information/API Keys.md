Some of you may have noticed that your Arena Net account has an API key feature: https://account.arena.net/applications 
This enable third party applications to read the status of your account. It is 100% safe, there is no chance that people will be able to hack into your account from this. There is a website that uses these API keys to show you everything about your account and even ranks it relative to other players who use the website. If you ever want to browse your achievements or see what the best players on the server have accomplished, this is just what you want: https://gw2efficiency.com/

---

**__How to create a GW2 API key__**
1️⃣ Go to https://account.arena.net/applications, Log in, and click the New Key button

2️⃣ Once you click on New Key, you’ll be given options to what information your API key will show when used. I recommend checking all the boxes, so you can just use the same API key everywhere. Once you’ve done that, you can give this API any name you like at the top and click CREATE API KEY at the bottom.

3️⃣ Once you’ve created your key, you’ll be redirected back to the previous window with your new API key ready to use. You can see the information the API key contains. To copy your API key for use on this Discord (or anywhere else), click on the papers icon.
